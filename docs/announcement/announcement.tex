\begin{adjustwidth}{1in}{1in}
\textit{\bf Abstract:}\\

\vspace{3mm}

\normalsize
\noindent In K–12 education, students often experience a lack of 
motivation and engagement in their academic work. ClassSaga is a 
full-stack web application developed with React, Node.js, Express, 
and MongoDB that introduces a virtual pet incentive system designed 
to encourage positive student behaviors. Teachers award points based 
on classroom performance, which students can then use to care for and 
enhance their virtual pets. The application incorporates core features 
such as pet care mechanics, a shop with purchasable items, and a leveling 
system that ties academic participation to in-game progression. ClassSaga 
is intentionally designed as a fun yet lightweight tool that promotes 
engagement and student buy-in without significantly disrupting instructional 
time. By integrating gamification with classroom management, the system aims 
to reinforce desired behaviors through consistent feedback and interactive 
progression.
\end{adjustwidth}
